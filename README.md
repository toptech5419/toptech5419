## 🔬 Research & Engineering Depth

### 🤖 MSc Dissertation — Semantic Visual SLAM &nbsp;·&nbsp; _in progress_ 🚧
**Integrating Keypoint Semantic Integration (KSI) into the open-source [pySLAM](https://github.com/luigifreda/pyslam) framework** for robust mapping in repetitive, perceptually-aliased environments such as agricultural and vineyard scenes. MSc research at the **University of Lincoln — Lincoln Centre for Autonomous Systems (L-CAS)**.

Standard visual-SLAM feature matching breaks down where scenes look alike — rows of identical vines or structures — causing tracking loss and drift. KSI enriches keypoint descriptors with **semantic context** so matching stays reliable where geometry alone fails.

- Building the end-to-end pipeline: sensor data → SLAM-ready format → reproducible runs
- Establishing a rigorous **baseline** (SuperPoint + LightGlue, RGB-D) before integration
- Integrating the **KSI** semantic feature front-end into pySLAM
- Evaluating trajectories against ground truth with `evo` (ATE / loop-closure metrics)

`Python` · `PyTorch` · `pySLAM` · `SuperPoint / LightGlue` · `RGB-D Visual SLAM` · `ROS bags` · `Docker / WSL2` · `evo`
